# Recursos do PDF LAINES

- `logo-laines.png`: cópia do emblema já usado em `src/assets/LogoLainesSidebar.png`, incluída aqui porque o contêiner do servidor é publicado separadamente do frontend.
- Sofia Sans regular/negrito e Sofia Sans Extra Condensed itálico 900: instâncias estáticas dos arquivos variáveis oficiais de [Google Fonts](https://github.com/google/fonts/tree/main/ofl/sofiasans) e [Google Fonts Extra Condensed](https://github.com/google/fonts/tree/main/ofl/sofiasansextracondensed). Os originais variáveis e as licenças OFL acompanham as instâncias para permitir reprodução e auditoria.
- Instâncias criadas com `fontTools.varLib.instancer.instantiateVariableFont` nos pesos 400, 700 e 900. Nenhuma fonte é baixada em tempo de execução.
